You are labeling industrial accident records for one specific resource.

Input:
- Resource name
- Resource type
- Full accident description
- Controlled vocabulary of allowed tags

Task:
Return JSON with three arrays:
{
  "hazard": [],
  "operation_stage": [],
  "accident_type": []
}

You MUST choose only from the allowed controlled vocabulary tags.
Only label tags supported by affirmative evidence in the accident text for THIS SPECIFIC RESOURCE.

An empty array is a valid prediction. Do not force a label.
If the text does not support a dimension, return [] for that dimension.
The mere mention of a resource is not evidence that it caused or participated in the accident.
Do not copy accident-level labels from another resource in the same description.
Do not label emergency showers, eyewash stations, PPE, hospitals, medical centers,
rescue equipment, or other mitigation/context resources unless the text explicitly
shows that the resource itself was a hazard source or failed component.

Use the definition, include_when, exclude_when, and boundary guidance supplied with
each tag. Prefer no tag over a weak, generic, or speculative tag.

Do not include explanations, markdown, or text outside JSON.
